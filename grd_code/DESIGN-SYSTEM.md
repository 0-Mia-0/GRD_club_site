# Spacing and layout tokens

Spacing, alignment, and structure
Layout logic

Full-width blocks stacked vertically
Strong left-alignment with large negative space on the right for decorative vertical labels
Large, rotated text elements and segmented geometric decoration are used as section framing
Content blocks are arranged with consistent margin-based alignment, not a highly flexible grid system
Verified structural values

Border radius: 7 px
Thick border width: 3.5 px
Thin border width: 1.5 px
Major sections are large full-width blocks with heights around 900 px
Navigation area and hero area appear in a large top section with fixed width styling
Content columns span left alignment and feature large margin distances
